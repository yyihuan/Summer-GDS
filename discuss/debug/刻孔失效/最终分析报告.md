该方法的作用：

2. 对每个多边形的顶点进行四舍五入处理

4. 替换原有多边形

## 二、为何会破坏 Via 功能

### 2.1 Via 结构的脆弱性

Via 的实现依赖于精确的布尔运算：

```python
# gds_utils/region.py::polygon2ring()
outer_region = cls.create_polygon(frame, fillet_config, outer_zoom=1)
inner_region = cls.create_polygon(frame, fillet_config, inner_zoom=-1)
result = outer_region - inner_region  # ← 关键：布尔减法
```

### 2.2 精度处理的问题

精度处理对 outer 和 inner 区域进行了不同步的坐标改变，导致原本应该精确相交的内外边界错位。

### 2.3 布尔运算失效的原因

KLayout 的布尔减法要求几何精确。如果 outer 和 inner 的坐标精度不一致，布尔运算可能失效。

## 六、结论

如果验证按预期进行，则可以得出：

✅ **精度处理 (`apply_global_precision`) 破坏了 via 功能**

具体机制：
1. 精度处理对 outer 和 inner 区域进行了不同步的坐标改变
2. 导致原本应该精确相交的内外边界错位
3. 布尔减法 `outer - inner` 无法正确计算
4. 最终导致 via 环形区域为空
