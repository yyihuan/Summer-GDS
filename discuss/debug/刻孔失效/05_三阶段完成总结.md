## 🔧 技术实现

### 核心创新

1. **精度/dbu 数学约束**
   ```
   precision / dbu = k (k必须是正整数)

   示例:
   ✓ 0.01 / 0.001 = 10
   ✓ 0.0001 / 0.0001 = 1
   ✗ 0.0001 / 0.001 = 0.1 (不允许)
   ```

2. **坐标精度保证流水线**
   ```
   原始顶点(μm)
     ↓ [四舍五入到precision]
   精度对齐顶点(μm)
     ↓ [offset/fillet操作]
   变换后顶点(μm)
     ↓ [转换为db坐标]
   整数db坐标(精确网格)
     ↓ [bool操作]
   精确结果(无浮点误差)
   ```

3. **前后端验证体系**
   ```
   前端 (JavaScript)
   - 实时验证 precision/dbu 比例
   - 即时用户反馈
   - 提前拒绝无效输入

   后端 (Python/Flask)
   - 独立服务器侧验证
   - 防止绕过前端验证的非法请求
   - 详细的验证错误报告
   ```

## 📋 使用指南

### 启用精度控制

**方法1: Web GUI**
```
1. 打开 Web GUI
2. 全局设置 → 数据库单位: 0.001
3. 全局设置 → 全局精度控制: 0.01
4. 系统验证 (实时显示)
5. 点击 "生成 GDS"
```

**方法2: YAML 配置**
```yaml
global:
  dbu: 0.001
  precision: 0.01  # ← 添加这行
```

### 禁用精度控制
```yaml
global:
  dbu: 0.001
  # precision 不指定 或设为 null
```

### 快速问题排查

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 精度显示错误 | 比例不是整数 | 确保 precision = dbu × k |
