- **比例验证**: 确保 `precision / dbu = 整数`

验证代码 (lines 245-270):
```python
# 验证全局精度参数
global_config = config_data.get("global", {})
dbu = global_config.get("dbu", 0.001)
precision = global_config.get("precision")

# 验证dbu范围
if not (0.00001 <= dbu <= 1.0):
    errors.append(f"dbu 必须在 0.00001 ~ 1.0 范围内，当前值: {dbu}")

# 验证precision（如果指定了）
if precision is not None:
    if not (0.00001 <= precision <= 1.0):
        errors.append(f"precision 必须在 0.00001 ~ 1.0 范围内，当前值: {precision}")
    else:
        # 验证precision/dbu的整数比关系
        ratio = precision / dbu
        if abs(ratio - round(ratio)) > 1e-10:
            errors.append(
                f"precision 和 dbu 不兼容: {precision} / {dbu} = {ratio:.6f}, "
                f"必须是整数倍关系!"
            )
```

#### 2.3 前端验证脚本 (lines 777-851)
完整的 JavaScript 验证函数 `validatePrecisionAndDbu()`:

**功能:**
1. 监听 dbu 和 precision 输入框的 change/input 事件
2. 实时验证精度和 dbu 的兼容性
3. 显示/隐藏警告提示
4. 添加/移除 CSS 错误样式类 (`is-invalid`)

**验证逻辑:**
- 如果 precision 为空，不进行验证（允许不控制精度）
- 检查精度和 dbu 是否为正数
- 计算比例并验证是否为整数
- 实时显示错误信息

**关键代码段:**
```javascript
function validatePrecisionAndDbu() {
    const dbu = parseFloat(dbuInput.value) || 0;
    const precision = precisionInput.value ? parseFloat(precisionInput.value) : null;

    // 如果precision为空,则不进行验证
    if (precision === null || precision === undefined ||
        precisionInput.value.trim() === '') {
        warningDiv.style.display = 'none';
        return;
    }

    // 计算比例
    const ratio = precision / dbu;
    const isValidRatio = Math.abs(ratio - Math.round(ratio)) < 1e-10;

    if (!isValidRatio) {
        warningDiv.style.display = 'block';
        warningText.textContent =
            `精度 (${precision}) 与 dbu (${dbu}) 不兼容: 比例为 ${ratio.toFixed(4)}, 必须为整数!`;
        dbuInput.classList.add('is-invalid');
        precisionInput.classList.add('is-invalid');
    }
}
```

## 前后端集成点

### 数据流向
```
前端输入表单
    ↓
JavaScript 实时验证 (validatePrecisionAndDbu)
    ↓ (数据有效)
AJAX 提交配置到后端
    ↓
/api/validate-config 端点验证
    ↓ (验证通过)
/api/generate-gds 调用 main.py
    ↓
main.py → GDS → Frame → 顶点精度转换
    ↓
生成 GDS 文件
```

### 前端验证的作用
1. **用户友好**: 即时反馈，无需提交即可知道错误
2. **减少网络请求**: 本地验证可以快速拒绝无效输入
3. **增强体验**: 清晰的错误信息帮助用户修正

### 后端验证的作用
1. **安全防护**: 不信任前端输入，服务器侧独立验证
2. **数据完整性**: 确保传入后端的参数有效
3. **错误报告**: 提供详细的服务器端验证结果

### 常见问题

**Q: 为什么我的精度设置显示错误?**
A: 精度必须是 dbu 的整数倍。例如，若 dbu=0.001，则 precision 可以是 0.001, 0.002, 0.003, ... 0.01 等，但不能是 0.0001。

**Q: 我可以省略精度设置吗?**
A: 可以。将 "全局精度控制" 字段留空即可，系统会跳过精度控制，行为与之前完全相同。

**Q: precision 和 倒角精度 有什么区别?**
A:
- **全局精度控制** (global.precision): 在生成 GDS 前对所有顶点四舍五入，简化几何
- **倒角精度** (global.fillet.precision): 圆弧倒角的离散化精度，控制倒角的光滑度
