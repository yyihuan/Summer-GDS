# 全局精度控制功能设计方案

## 1. 问题背景

当前系统存在两个限制：
1. **固定的 dbu**：硬编码为 0.001 μm（1 nm），无法支持更小的精度需求
2. **倒角精度独立**：倒角精度（fillet.precision）与全局精度分离，无法统一管理

当精度需求为 0.0001 μm 时，现有的 0.001 μm dbu 无法精确表示，导致坐标计算偏差。

---

## 2. 数学基础

### 2.1 精度与 dbu 的关系

在 GDS 中，所有坐标必须用**整数倍的 dbu** 表示：

```
实际坐标 = db坐标 × dbu

其中：
- db坐标 必须是整数
- dbu 是最小可表示单位
```

### 2.2 精度控制的约束

用户设定的 `precision`（精度）用来四舍五入顶点，必须满足：

```
precision / dbu = k (k 为正整数)

示例：
✓ precision=0.01, dbu=0.001  → 0.01/0.001 = 10 ✓
✓ precision=0.0001, dbu=0.0001  → 0.0001/0.0001 = 1 ✓
✗ precision=0.0001, dbu=0.001  → 0.0001/0.001 = 0.1 ✗ 不是整数
```

### 2.3 坐标精度保证

**坐标转换流程**：

```
用户输入顶点 (μm)
    ↓
[精度四舍五入]  ← precision
    ↓
精度对齐后的顶点 (μm)
    ↓
[偏移/倒角变换]
    ↓
变换后的顶点 (μm)
    ↓
[转换为db坐标]  ← dbu: db_coord = round(um_coord / dbu)
    ↓
整数db坐标
    ↓
[bool操作]  ← 所有参与bool的顶点都在同一整数网格上
    ↓
GDS输出
```

### 2.4 bool操作安全性证明

设两个Region参与bool操作：
- Region A 和 Region B 的顶点都通过相同的 precision 和 dbu 处理
- 精度转换后：顶点被对齐到 `precision` 的网格
- db坐标转换后：顶点被对齐到 `dbu` 的网格
- 由于 `precision % dbu == 0`，所有对齐点都在同一整数网格上
- **bool操作结果精确，无浮点误差**

## 3. 系统设计

### 3.1 参数配置

**YAML 配置格式**：

```yaml
global:
  dbu: 0.0001              # 数据库单位（μm），从YAML传入
  precision: 0.0001        # 顶点精度（μm），新增参数
  fillet:
    interactive: false
    # precision 字段在此处移除，全局精度控制统一使用 global.precision

gds:
  output_file: "output.gds"
  cell_name: "TOP"
  default_layer: [1, 0]

shapes:
  - type: "polygon"
    vertices: "0,0:10,0:10,10:0,10"
    layer: [1, 0]
```

### 3.2 参数验证规则

1. **dbu 范围**：0.00001 ~ 1.0 μm
2. **precision 范围**：None 或 0.00001 ~ 1.0 μm
3. **兼容性检查**：当 precision != None 时，必须满足 `precision % dbu == 0`
4. **错误处理**：不满足条件时抛出 ValueError 并记录日志

### 3.3 模块职责划分

| 模块 | 职责 |

| **main.py** | 参数解析、验证、传递给GDS |

| **gds_utils/utils.py** | 精度转换函数、动态um_to_db |
| **gds_utils/frame.py** | Frame创建时应用精度转换 |
| **gds_utils/region.py** | Region传递精度参数 |

## 5. 详细实现规范

### 5.1 参数验证函数（utils.py）

```python
def validate_precision_dbu(precision, dbu):
    """
    验证 precision 和 dbu 的兼容性

    参数:
        precision: 精度（μm），可以为 None
        dbu: 数据库单位（μm）

    抛出:
        ValueError: 不满足兼容性条件

    返回:
        True 表示验证通过
    """
    if precision is None:
        return True

    if not (0.00001 <= dbu <= 1.0):
        raise ValueError(f"dbu 必须在 0.00001 ~ 1.0 范围内，当前值: {dbu}")

    if not (0.00001 <= precision <= 1.0):
        raise ValueError(f"precision 必须在 0.00001 ~ 1.0 范围内，当前值: {precision}")

    # 检查兼容性
    ratio = precision / dbu
    if ratio != int(ratio):
        raise ValueError(
            f"precision 和 dbu 不兼容：{precision} / {dbu} = {ratio}，"
            f"必须是整数倍关系！"
        )

    return True
```

### 5.2 精度转换函数（utils.py）

```python
def round_vertices(vertices, precision):
    """
    四舍五入顶点到指定精度

    参数:
        vertices: 顶点列表 [(x1,y1), (x2,y2), ...]
        precision: 精度（μm），None 表示不转换

    返回:
        转换后的顶点列表
    """
    if precision is None:
        return list(vertices)

    rounded = []
    for x, y in vertices:
        x_rounded = round(x / precision) * precision
        y_rounded = round(y / precision) * precision
        rounded.append((x_rounded, y_rounded))

    logger.debug(f"顶点精度转换：precision={precision}, 点数={len(rounded)}")
    return rounded
```

### 5.3 全局dbu管理（utils.py）

```python
# 全局dbu变量
_current_dbu = 0.001

def set_global_dbu(dbu_value):
    """设置全局dbu（在GDS初始化时调用）"""
    global _current_dbu
    _current_dbu = dbu_value
    logger.info(f"设置全局 dbu = {dbu_value} μm")

def get_global_dbu():
    """获取当前全局dbu"""
    return _current_dbu

def um_to_db(v):
    """转换微米到数据库单位"""
    global _current_dbu
    db_value = round(float(v) / _current_dbu)
    return int(db_value)
```

## 7. 风险评估与缓解

| 风险 | 等级 | 缓解策略 |
|------|------|--------|
| bool操作精度丧失 | 高 | 严格验证precision/dbu关系，统一应用精度转换 |
| 向后兼容性破坏 | 中 | precision=None时完全回退，dbu默认0.001 |
| 浮点计算误差 | 中 | 使用round()而非int()，确保整数对齐 |
| 配置错误 | 低 | 前置验证，明确错误信息 |
