## YAML 配置示例

### 向后兼容配置（现有）
```yaml
global:
  dbu: 0.001
  # precision 不指定

shapes:
  - type: "polygon"
    vertices: "0,0;10,0;10,10;0,10"
```

### 高精度配置（新支持）
```yaml
global:
  dbu: 0.0001        # 0.1 nm 精度
  precision: 0.0001  # 精度也是 0.1 nm

shapes:
  - type: "polygon"
    vertices: "0,0;1.2345,0;1.2345,2.3456;0,2.3456"
```

### 粗粒度配置（新支持）
```yaml
global:
  dbu: 0.001         # 1 nm
  precision: 0.01    # 精度是 10 nm

shapes:
  - type: "polygon"
    vertices: "0,0;10,0;10,10;0,10"
```
